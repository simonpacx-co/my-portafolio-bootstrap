# Portafolio con React.js y Bootstrap

Portafolio web de Jane Doe hecho con React (Vite), Bootstrap y React-Bootstrap.

## Ejecutar
```bash
npm install
npm run dev
```
Abrir http://localhost:5173

## Estructura
```
src/
├── components/   Header, Intro, SkillsSection, SkillCard, ProjectsSection,
│                 ProjectItem, RecommendationsSection, RecommendationCard,
│                 LeaveRecommendationForm, Footer, ScrollToTopButton
├── data/         portfolioData.js (datos que se pasan por props)
├── App.jsx       componente principal
├── App.css       estilos personalizados
└── main.jsx      punto de entrada
```
